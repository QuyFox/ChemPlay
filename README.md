# Đố Vui Hóa Học — Tự động Build APK (Capacitor + GitHub Actions)

## Hướng dẫn nhanh
1. Tải file game `chemistry_quiz_mobile.html`, đổi tên thành `index.html` rồi chép đè vào `www/index.html`.
2. Đẩy toàn bộ thư mục dự án lên một repository mới trên GitHub (Public hoặc Private).
3. Mở tab **Actions** trên GitHub -> đợi workflow **Build Android APK** chạy xong (~3–4 phút).
4. Bấm vào lượt chạy vừa hoàn thành -> kéo xuống mục **Artifacts** -> tải `DoVuiHoaHoc-APK`, giải nén và cài file `DoVuiHoaHoc.apk` lên điện thoại Android.
